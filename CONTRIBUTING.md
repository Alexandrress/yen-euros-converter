Thanks for your interest in contributing to this project! We welcome improvements, bug fixes, and documentation updates.

How to contribute

1. Open an issue to discuss larger changes or features before implementation.
2. Fork the repository and create a branch named `fix/short-description` or `feat/short-description`.
3. Make changes in your branch.
4. Format Dart code:

```
dart format .
```

5. Run tests:

```
flutter test
```

6. Open a pull request describing your change. Link to any related issue.

PR checklist

- [ ] The change is small and focused
- [ ] Tests added or existing tests updated where applicable
- [ ] Code formatted with `dart format`
- [ ] CI passes (if configured)

If you're unsure about any step, open an issue and we'll help.
