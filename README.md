# yen_euros_converter

A small Flutter app to convert between Euros and Japanese Yen.

Highlights
- Lightweight, single-purpose demo app
- Simple UI for converting between EUR and JPY
- Good starting point for Flutter learners

- Overview

- Run locally

## Requirements

- Flutter SDK (stable channel). See https://flutter.dev/docs/get-started/install
- A device or emulator (Android/iOS) or web-enabled Flutter tooling

## Run locally

1. Install dependencies:

```
flutter pub get
```

2. Run on a connected device or emulator:

```
flutter run
```

3. Run tests (if present):

```
flutter test
```

## Build

- Android release: `flutter build apk`
- iOS release: `flutter build ios` (requires macOS and Xcode)

## Project structure

- `lib/` — main Dart source. See `lib/main.dart` for app entry.
- `android/`, `ios/`, `windows/`, `web/` — platform folders generated by Flutter
- `test/` — widget/unit tests
